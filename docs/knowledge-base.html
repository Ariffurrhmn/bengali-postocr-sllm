Framing and scope

D01 Research question: zero-shot correction that bolts onto any engine

Chose Test whether a small open-weight language model, used only as a post-processing step with no training, lowers CER and WER on Bengali OCR output, and whether the effect holds on two OCR engines.

Alternatives Training a correction model, or tuning the OCR engine itself. The log does not list other framings.

Why The intended users (archives, government offices, NGOs in Bangladesh) usually have no GPU. A layer that works on any engine without retraining would be the cheapest fix if it worked. The log says no earlier work had tested small-model post-OCR correction for Bengali, or engine independence for any language.

Cost Every later choice (free compute, no fine-tuning, one fixed prompt) follows from keeping the setup this cheap. A fine-tuned model was only tried later as a pilot (D47).

D02 Base paper: Kanerva et al. 2025, 'No Free Lunches'

Chose Use Kanerva, Ledins, Käpyaho and Ginter (RESOURCEFUL 2025) as the method template.

Why It is the closest precedent: zero-shot open-weight LLMs on historical OCR, scored with CER/WER, across languages. Open models helped English but made Finnish, the lower-resource language, worse. That made Bengali an open question.

Cost Three things were taken from it: NFC before scoring (D21), segments of about 200-300 subwords (D19), and an alignment filter for overgeneration that was planned but never built (D23).

D04 Dataset: British Library historical Bengali print (REID2019)

Chose 'Ground truth transcriptions for training OCR of historical Bengali printed texts' (British Library, Two Centuries of Indian Print, with PRImA and Jadavpur University; ICDAR 2019 REID competition), version 2, DOI 10.23636/1168. Books printed 1713-1914.

Alternatives bbOCR / BCD3 (about 88.5k words) as a fallback. BaDLAD was rejected (layout labels only, no transcriptions) and BN-HTRd too (handwriting).

Why It mirrors the base paper's historical-print design. Page images with PAGE-XML ground truth allow page-level CER/WER. Images are out of copyright and the transcriptions are public domain.

Cost Results describe old print (ornate type, verse, title pages) and may not carry over to modern documents. This is a stated limitation.

D08 Two engines, Tesseract 5.3.4 and EasyOCR 1.7.2, default settings

Chose Run both engines on every page with default settings. Tesseract uses the tessdata_best Bengali model in a project-local folder.

Bengali script units: conjunct, vowel sign, virama, danda, ZWJ, khanda-ta

Bengali writes consonant clusters as one glyph (conjunct: consonant + virama + consonant). Vowel signs (matras) attach to consonants. The virama (hasanta, U+09CD) removes a consonant's inherent vowel. The danda is the sentence mark. Zero-width joiner/non-joiner (U+200D/U+200C) control how conjuncts are drawn. Khanda-ta can be stored as U+09CE or as a three-code-point sequence.

In this project Character-class analyses group errors by these units. Removing ZWJ/ZWNJ changes CER by at most 0.003; unifying khanda-ta changes nothing.

Holm-corrected Wilcoxon decides significance in the primary family; the bootstrap gives effect sizes with unadjusted intervals. They disagree in a few cells (Qwen3 1.7B and Phi-4-mini on EasyOCR; ByT5 on both engines), and the README and tables say which rule the marks follow.
